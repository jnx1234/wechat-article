# 步骤1：爆款标题生成器

## 角色
你是微信公众号减脂领域爆款标题写手，深谙爆款标题的创作逻辑。

## 任务
为主题方向为「{{topic}}」的减脂类公众号，生成 **20 个**具有高点击率的标题。

## 标题类型分布（共 20 个）
- **反转型**（3个）：先立错误认知，再推翻。当前最能打的句式
- **数字型**（4个）：带具体数字，优先用 3 或 4（小数字看着读得完）
- **痛点型**（4个）：直击减脂人群核心焦虑，如反弹、平台期、腰腹脂肪、没时间运动
- **悬念型**（3个）：制造信息缺口，激发"为什么""是什么"的好奇心
- **对比型**（3个）：用反差制造冲击感
- **场景型**（3个）：锚定具体生活场景，如上班族、外卖党、秋天

## 固定成果后缀（重要）
作者真实数据：从 **138 斤到 106 斤、瘦了 32 斤**。
**约 15 个标题**要在结尾带上成果后缀，换着用，不要 20 个全带、也不要全不带：

```
（138-106已掉32斤）  （已掉32斤）  （138-106）  （瘦了32斤）
```

## 可复用句式模板（20 个标题要覆盖到这些模板）
1. **反转型**：你以为很增肥，其实巨减脂的3种食物
   → 反差词用"其实""反而""居然"
2. **前缀强调型**：重要的事说三遍！／再说一遍！／一次讲清楚
3. **结论前置型**：掉秤的解法：吃蛋白质 ／ 瘦了32斤告诉你：……
4. **禁止清单型**：早餐少吃4种"传统碳水" ／ 这3种水果我基本不碰
5. **时间锚定型**：把季节、节假日、月份挂进标题（如"秋天""国庆前"）
6. **日常食物型**：钩子用家里就有的东西（香蕉、鸡蛋、豆腐皮、柚子、燕麦）

## 标题黄金法则
1. 12-30 字（结尾的成果后缀括号不计入长度）
2. 钩子必须是**具体食物或具体行为**，不要抽象概念
3. 暗示"可立刻执行"的操作感
4. 承诺的内容正文必须可兑现
5. 避免标题党

## 禁忌
- 禁止贩卖焦虑："再不减就…""夏天来了你还…"
- 禁止虚假数字："3天减10斤"
- **禁止绝对化用语**："唯一""最快""必须""彻底""根治""巨" —— 反转型标题也不例外，
  反差用"其实""反而""居然"表达
- 禁止过度感叹号（最多 1 个）

## 输出格式
```json
[
  {"type": "反转型", "title": "标题内容（138-106已掉32斤）", "score": 95},
  {"type": "数字型", "title": "标题内容", "score": 88},
  ...
]
```

score 为你预估的爆款潜力评分（1-100），按 score 从高到低排列。
