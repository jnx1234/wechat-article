## AI 味检测与修复

### 1. 过渡词替换
| AI 感表达 | 修 改为 |
|-----------|---------|
| 首先/第一 | 先说 / 第一件事 / 开头先 |
| 其次/第二 | 接着说 / 然后呢 / 还有个 |
| 再次/第三 | 还有个事儿 / 最关键的 |
| 最后 | 最关键的来了 / 收个尾 |
| 综上所述 | 说白了就是… / 划重点啦 |
| 因此/所以 | 这就意味着 / 所以啊 |
| 此外/另外 | 对了 / 哦还有 / 顺便说一句 |
| 值得注意的是 | 敲黑板！ / 注意看这里 |
| 从某种程度上来说 | 多多少少 / 某种程度上 |
| 在…的过程中 | 直接省略或简化 |
| 进行（如"进行运动"） | 直接动词 |

### 2. 句式自然化
- 把"的"字过密的句子拆散（连续 3 个"的"必须改）
- 把"性""化""度"等书面后缀口语化
  - "有效性" → "管不管用" / "有没有用"
  - "显著性" → "肉眼可见的" / "实打实的"
  - "依赖性" → "上瘾" / "离不开"
- 长句（超过 30 字）拆成短句
- 把被动句改主动句
  - "被很多人忽视" → "很多人都没注意到"

### 3. 增加口语化连接
在适当位置加入口语化过渡：
- "说真的，…"
- "你猜怎么着？"
- "这就说到点子上了——"
- "来，给你捋一捋…"
- "故事还没完——"
- "扎心了吗？别急，还有更扎心的…"

### 4. 删除 AI 特征表达
必删清单：
- ❌ "在当今社会" / "随着生活水平的提高"
- ❌ "不可否认的是" / "毋庸置疑"
- ❌ "众所周知" （读者不知道）
- ❌ "一定程度上" / "某种意义上" （模糊词）
- ❌ "值得注意的是" → 直接说内容
- ❌ 任何"总而言之/综上所述/总的来说"开头的段落
- ❌ 连续三个"、"， 的排比句式

### 5. 增加真实感细节
- 在不影响准确性的前提下，增加生活化细节
- "一杯" → "一大杯"（更有画面感）
- "运动" → "练到出汗"（更具体）
- "注意饮食" → "把零食换成黄瓜条"（可执行）

## 自然度自检清单
- [ ] 朗读一遍，是否像朋友在跟你聊天？
- [ ] 有没有哪个句子让你觉得"这不像人说的话"？
- [ ] 过渡是否流畅，没有明显的"切换感"？
- [ ] 是否存在连续两个"首先…其次…"式的段落？

## 输出格式
直接输出去 AI 味后的完整 Markdown 文章，并附上一句话说明做了哪些关键改动。
