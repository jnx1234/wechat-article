# 主题池

`/wechat-gen` 未指定 `--topic` 时，从这里选 **1 个大类 + 1 个具体选题**，
把具体选题作为 `args.topic` 传给工作流脚本。

各大类后面的标注是它承担的作用，排期时注意搭配，
不要连续多天都发同一类（比如连着发"单一食物"会显得内容窄）。

其中「单一食物」类按文末的展开模板生成选题，不必穷举。

## 单一食物类选题的展开模板

这一类的选题不用穷举，按下面的玩法 × 食物自己生成：

**玩法**

- 一个食物，5 种吃法
- 同一种食物，不同做法
- 两个食物 PK
- 超市货架研究

**每个具体食物，按这 6 问展开**

1. 它有什么特点？
2. 减脂期为什么值得 / 不值得关注？
3. 怎么选？
4. 多少比较合适？
5. 怎么烹饪？
6. 和什么搭配？给出 2～3 个具体食谱
